# AGENTS.md

## Testing

- Después de agregar o cambiar funcionalidad, no ejecutar tests ni verificaciones (unitarios, e2e, lint, typecheck, builds de verificación, smoke ni pruebas manuales) salvo que el usuario lo pida por escrito y de forma explícita.
- Un pedido de implementar, corregir o continuar no autoriza a correr tests.

## Documentación

- El documento de implementación es `docs/blueprint/BLUEPRINT-BACKEND.md` (v2).
